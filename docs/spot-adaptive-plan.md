# V12 자동 재조정 사전 계획

후보 네 개를 고정한다. 주간과 월간 각각 누적(2018-09-01 이후) 및 최근 365일의 섀도 포트폴리오 점수를 사용한다. 주간은 월요일, 월간은 월초 UTC 00:00에 검토한다. 양쪽 모두 분기 초에 기본 V12 목표를 갱신한다. 각 5년 창과 검증 창은 현금 및 V12 모드에서 독립 시작한다. 섀도 성과는 창 시작 전 가용 이력도 사용한다.

섀도는 V12, V35-45, 현금의 독립 포트폴리오다. BTC 섀도는 기존 분기 규칙과 비용·수량 모델을 적용하고 현금 이자율은 0이다. 점수는 관측 구간 순수익률 - 0.5 × 일별 종가 MDD다. 최소 365일의 달력 이력과 일별 종가 관측 350개가 필요하다. 검토 직전 확정 일봉까지만 사용한다. V12 대비 점수가 5%p 이상 높은 대안만 선택하고 둘 다 가능하면 점수가 높은 쪽을 택한다. 동률은 V35-45 우선이다. 점수 요건 상실 또는 데이터 부족 시 기본 V12로 복귀한다.

대안 전환 및 교체 사이 최소 28일. 기본 복귀는 이 제한을 받지 않는다. 모드가 바뀌어도 기존 V12 목표에서 최대 15%p만 하향한다. V35-45 모드는 두 목표의 중간값을 사용하되 15%p 한도를 지키고, 현금 모드는 V12 목표에서 최대 15%p를 내린다. 기본 분기 업데이트로 인한 비중 변화에는 이 한도를 적용하지 않는다. 전략 주문은 창 시작, 분기 초, 모드 변경 시점에만 발생하며 정분 봉 누락 시 해당 주문은 생략한다. 미래 봉으로 보간하지 않는다.

고정 V12, BTC 보유, V35-45와 기존 51개 및 2024-01~2026-10을 비교한다. 실행 비용은 기존 0.10%·0.075%와 동일. 합격은 두 비용 모두 51/51 달성, 최저 배수와 검증 수익률이 고정 V12 이상, 최대 롤링 MDD와 검증 MDD가 고정 V12 이하, 검증 및 51개 창의 최대 연평균 전략 주문 4회 이하의 동시 충족이다. 종료 평가 매도는 빈도에서 제외하되 비용 및 회전율에 포함한다. 성과 열위 창은 전체 목록을 기록한다. 모든 후보를 사전 고정한 뒤 한 번 평가하며 결과로 재선정하거나 조정하지 않는다. 기존 고정 전략의 결과는 이미 알려져 있어 독립 신규 표본으로 해석하지 않는다.
