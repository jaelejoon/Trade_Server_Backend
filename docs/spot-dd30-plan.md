# 현물 5년 두 배·낙폭 30% 탐색 사전 계획

신규 16개를 고정한다. 기존 V12, T12, v2 방어형, BTC 보유는 비교 기준이다.
- V12 분기 변동성 목표 35%, 50% × 최대 BTC 비중 45%, 60% = 4개.
- T12 월초 신호 전환, 상승 목표 40%, 55%, 70% × 하락 목표 0%, 10% = 6개.
- 이중 추세(완료 월말 종가가 6개월 및 12개월 SMA 초과)에서만 BTC 45%, 60%, 75% × 월초 신호 전환, 분기 초 정기 조정 = 6개. 분기 후보는 시작월에도 목표를 적용한다.

PR #13의 분봉 데이터·구간·비용·주문·종료 규칙을 재사용한다. 수수료 0.10%로 개발 창 17개(2017-09~2019-01 시작)만 평가한다. 모든 개발 창에서 MDD ≤30%, 연평균 시장 주문 ≤4인 후보 중 2배 달성 수, 최저 배수, 중앙값 순으로 선정한다. 동률은 위 열거 순서다. 만족 후보가 없으면 선정 없음으로 고정한다. 이후 전체 51개와 2024-01~2026-10을 두 비용 조건으로 한 번 평가한다. 30/40/50% 이하 최적 최저 배수는 전체 평가의 사후 비교로 표시하며 후보를 승격하지 않는다.
