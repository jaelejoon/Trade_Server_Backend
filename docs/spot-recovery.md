# 현물 보호주문 복구 정책

BTCUSDT 봇이 매수한 거래소 확인 체결의 순보유량을 PostgreSQL 기록으로 확정한다.
매도 체결량과 BTC로 부과된 수수료를 차감한다. 거래소 잔고가 봇 순보유량보다
크면 초과분을 건드리지 않고 로그와 알림을 남긴다. 잔고가 더 적으면 작은
수량만 처리하고 불일치를 알린다. 주문 가능 수량은 거래소의 사용 가능 잔고로
한 번 더 제한한다.

기록이 없거나 수량을 확정할 수 없으면 매도와 신규 진입을 중지하고 알린다.
재시작 시 봇의 보호주문을 식별하고, 수량이 확인된 보유분에 보호주문이 없으면
OCO를 다시 등록한다. 재등록에 실패하면 봇 보유분 중 매도 가능한 수량만
시장가로 비상 매도한다. OCO 응답이 불명확하면 주문 목록을 조회하고
이미 체결됐거나 잠긴 수량을 확인한다.

자동매매는 기본 중지다. 이 단계의 봇 주문은 현물 테스트넷에서만 가능하며
전역·사용자·계정 허용 조건을 모두 적용한다. 주문 전 클라이언트 ID와 보호
가격을 DB에 기록한다. 매수 주문과 보호주문의 체결은 거래소 주문 ID로 조회한
개별 체결을 검증한 후 원장에 중복 없이 적재한다. 기존 보호 주문의 상태를
확정할 수 없거나 매수 일부 체결이 계속 열려 있으면 계정을 중지한다.
OCO 결과 미확정 상태에서도 추가 매도는 중지한다.

알림은 오류 로그를 남기고 관리자 GET /trading/error-logs로 제공한다.

현물 봉은 spot_candles_1m에 적재한다. 기존 candles_1m 데이터는 보존하며
현물 신호와 백테스트에서 읽지 않는다. 현물 전용 계정을 등록하고 캔들을 다시
가져와야 한다.
