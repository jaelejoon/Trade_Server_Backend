```sh
OPENBLAS_NUM_THREADS=1 python scripts/search_spot_2x.py /path/to/spot-archives development selection.json
OPENBLAS_NUM_THREADS=1 python scripts/search_spot_2x.py /path/to/spot-archives evaluation selection.json > evaluation.json
```

MDD는 분봉 종가 평가자산으로 계산했다. 수수료를 USDT 등가액으로 적용했다. 전체 롤링은 개발 창이 포함된 역사적 평가이며, 월간 시작 창이 크게 겹친다. 검증 성과는 34개월이다.
