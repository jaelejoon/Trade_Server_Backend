# V12 자동 재조정 서버 사양 초안

기본 모드는 고정 V12다. 자동 모드는 운영 판단을 거친 뒤 별도 검증 환경에서 활성화하는 후보 사양이다.

- 입력은 Binance BTCUSDT 현물 완료 1분봉, UTC 인덱스, V12/V35-45의 월말 지표, 두 섀도 포트폴리오의 순 일별 평가자산과 현금 가치, 적용 수수료, 마지막 모드와 변경 시각이다. UTC 일별 관측은 마감한 날짜의 마지막 가용 분봉으로 표시한다. 운영 수집 지연 및 최신 완료 봉 부재는 별도 검사한다.
- 검토 시각은 주간 월요일 또는 월간 1일 UTC 00:00(KST 09:00), 기본 목표 갱신은 분기 첫날 같은 시각이다. 마감 봉 확인 후 해당 경계의 검토를 처리하고 유효 시간이 지난 요청은 추격하지 않는다. 기준 시각 이후 봉으로 결정을 갱신하지 않는다.
- 출력은 decision_id, 규칙 버전, 데이터 기준 UTC, 모드(V12/V35-45/CASH), 기본 BTC 목표 비중, 조정 BTC 목표 비중, 유효 시각, 사유다. 두 대안은 실제 전량 현금 전환을 뜻하지 않는다. 기본 대비 목표 차이는 최대 하향 15%p다. 모드 변경에는 최소 28일을 적용하고 기본 복귀는 즉시 허용한다.
- 데이터 또는 산출 오류 시 마지막 유효 V12 분기 목표를 유지하고 해당 자동 변경 주문을 보류한다. 유효한 V12 목표가 없으면 신규 자동 주문을 보류한다. 검토 재시도 및 재기동 시 계정·전략·예정 UTC 시각으로 중복 결정과 중복 주문을 막고, 마지막 확정 모드 및 변경 시각을 복원한다.
- 검토 성공·실패, 시작/종료 UTC, 데이터 범위·누락 개수, 방법 및 파라미터 버전, 섀도 수익률·낙폭·점수, 선택 전후 모드/비중, 최소 유지 기간 판정, 변경 이유·건너뛴 사유를 기록한다. 실행 후에는 체결 주문 수·명목거래액·수수료를 연결한다. 인증정보는 기록에 포함하지 않는다.
- 일치 테스트는 입력을 같은 마감 데이터로 재생해 목표·타임스탬프를 대조하고, 결측·재시도·중복 실행·기본 복귀·분기와 주간 검토 동시 발생을 포함한다. 시가와 실제 주문 사이의 지연 및 체결 괴리는 테스트넷에서 따로 측정한다.
