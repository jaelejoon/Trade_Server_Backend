# BTC 현물 5년 2배 탐색 사전 계획

기준 브랜치는 PR #9의 c863fade다. 신규 후보는 아래 10개로 고정한다. 비교 기준은 PR #9 v2 방어형과 BTC 단순 보유다. 이동평균과 모멘텀은 완료한 UTC 월봉만 사용한다. 주문은 월초 첫 1분봉 시가에 평가하고 해당 시각 분봉이 비면 주문을 건너뛴다. 월말 마지막 분봉이 없으면 해당 월 종가를 결측으로 취급한다.

분기 규칙은 시작월에도 당시 가용한 목표를 적용한다. 월간 신호 전환 규칙은 해당 월초의 유효 신호로 시작한다. 모든 창은 10,000 USDT부터 독립 시작하고 마지막 분봉 종가에 정리한다. 수수료 편도 0.10%·0.075%, 슬리피지 편도 0.02%, 수량 단위 0.00001 BTC, 최소 5 USDT. 현물 롱만 허용한다. 거래 빈도는 리밸런싱을 포함한 실제 체결 주문 수로 재며 구간 종료 평가 매도는 별도 처리한다. 연 4회 이하를 빈도 기준으로 사용한다.

개발은 2017-09~2019-01 시작의 완전한 5년 창 17개에 한정한다. 0.10% 기준 모든 개발 창에서 연 4회 이하인 신규 후보 중 2배 달성 수, 최소 배수, 중앙값 순으로 높은 후보 하나를 고정한다. 동률은 표의 순서다. 이후 고정한 전체 후보와 비교 기준을 검증 2024-01~2026-10 및 전체 롤링 51개에서 한 번 평가한다. 보수적으로 51개 및 검증 구간 모두에서 연 4회 이하인지도 표시한다. 검증 후 후보·규칙·파라미터를 수정하거나 다른 후보를 승격하지 않는다. 51개에는 개발 창이 겹쳐 있으며 검증 기간의 베이스라인은 이전 분석에서 이미 알려져 있다.
