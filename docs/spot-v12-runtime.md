# BTCUSDT 현물 V12 주간 누적형 실행

기준은 PR #15의 4bb47fd다. 월말 마지막 정분 봉의 종가를 사용하며,
최근 12개월 평균을 엄격히 초과할 때 목표 변동성 70%를 최근 6개 월수익률의
연율 표준편차로 나눈 값으로 기본 비중을 정한다. 비중 상한은 100%다.
V35-45의 목표 변동성은 35%, 상한은 45%다. 주간 검토는 월요일 UTC
00:00, 기본 갱신은 분기 첫날 같은 시각이다. 2018-09-01부터 누적 섀도
계좌를 운용하며, 관측 자산 순수익률에서 MDD의 절반을 뺀 점수를 사용한다.
최소 365일, 350개 일별 관측과 점수차 5%p를 요구한다.

PostgreSQL의 봇 상태에 UTC 처리 기준일, 섀도 계좌, 결정 및 주문 의도,
마지막 모드 변경 시각을 저장한다. 운영 계산은 기존 현물 봉 적재 경로를
전제로 한다. 종료된 분봉의 UTC 경계 시가와 전날 마지막 봉을 읽으며,
기록한 날짜 이후만 읽는다. 초기 역사 적재를 완료한 뒤 시작한다.
이미 봉이 처리된 날짜를 뒤늦게 수정하거나 적재하면 저장된 섀도 상태는
자동 수정되지 않는다.

서버 주문 유효 범위는 UTC 00:01~00:04다. 전날 마지막 정분 봉과
경계 시가가 확인되어야 한다. 늦은 검토는 기록하고 주문을 보류한다.
모의 계좌 초기값은 10,000 USDT, 편도 수수료는 10bp다. 모의 체결은
경계 시가를 사용한다. 섀도 계좌에는 연구의 2bp 슬리피지를 적용한다.
실제 테스트넷 체결가는 주문 후 확인한다.
명시적으로 켜진 기존 검증 서버 스위치가 모의 경로에 우선하되
전역 DRY_RUN과 실거래 차단 규칙은 그대로 적용한다. 계좌의 유효 사용자
권한과 기존 테스트넷 환경 제한도 적용한다. 열린 주문 또는 불확실한
보유량을 발견하면 주문을 보류한다. V12는 비중 조정 규칙이므로 기존
OCO를 취소하거나 새로운 손절·익절 기준을 임의로 만들지 않는다.
미확정 주문은 재기동 시 저장한 ID로 조회하고 재전송하지 않는다.

관리자 조회는 GET /trading/accounts/{id}/strategy다. 과거 대조는 PR #15
고정 워크트리와 동일한 Binance 공개 월별 분봉 ZIP으로 실행한다.

```sh
PYTHONPATH=. python scripts/check_spot_v12_parity.py ../v12-reference ../spot-public > v12-parity.csv
```

3번이다. 총 381개 날짜의 모드·비중·전환 여부가 모두 일치했다.
